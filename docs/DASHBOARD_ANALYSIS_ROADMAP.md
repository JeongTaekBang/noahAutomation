## 2. 핵심 분석 포인트 (액추에이터 업계 관점)

### 2.1 고객 집중 리스크 — 가장 시급

**현상**: ASC 단독 32%, Top 5 = 69%. 액추에이터는 프로젝트 기반이라 대형 고객 이탈 시 매출 절벽.

**모니터링 방법**:
- 고객 분석 페이지 → Pareto 차트에서 Top 5 누적비중 추이 추적
- 월별로 집중도가 심화되는지/개선되는지 확인
- HHI 지수 변화 추이

**임계값**: Top 1 고객 > 30%, Top 5 > 70% → 경고

### 2.2 납기 준수율 (OTD) — 고객 신뢰의 핵심

**현상**: 액추에이터는 프로젝트 일정에 연동되므로 OTD가 재주문/장기 계약의 결정 요인.

**모니터링 방법**:
- 제품별/고객별 OTD를 주간 단위로 확인
- OTD 낮은 건의 원인: 공장 리드타임? PO 확정 지연? 선적 지연?
- 오늘의 현황 → 납기 현황에서 미완료 건 추적

**임계값**: 전체 OTD < 85% → 즉시 원인 분석

### 2.3 수출/국내 포트폴리오 밸런스

**현상**: 수출 63% / 국내 37%. 수출 주문이 6배 크지만 환율·물류 리스크도 큼.

**모니터링 방법**:
- 수주/출고 페이지에서 시장별 필터로 각각 확인
- 월별 수출 비중이 70% 이상으로 편중되면 리스크 신호
- 환율(USD/EUR) 변동 시 KRW 환산 매출 영향 체크

### 2.4 수익성 이상 징후

**현상**: 표준품 vs 커스텀 스펙에 따라 마진 편차가 큼.

**모니터링 방법**:
- 수익성 페이지 → 저마진 경보(< 20%) 주시
- 모델별 마진에서 특정 제품이 지속 저마진이면 가격 정책 재검토
- 대형 고객(ASC 등)의 마진이 평균 이하인지 확인 — 볼륨 할인 과도 여부

### 2.5 Backlog Health

**현상**: 현재 40.3억원 (약 2개월치). 액추에이터 사업의 건강 바로미터.

**모니터링 방법**:
- Order Book → Backlog Cover가 1.5~3개월 범위 유지되는지
- Past Due Ratio 증가 추세면 공장 capacity 또는 자재 이슈 의심
- 월별 워터폴에서 Input > Output (B2B > 1) 유지 확인

## 3. 대시보드 부족한 부분

### 3.1 현재 데이터로 즉시 추가 가능

#### A. 미수금/입금 분석 (PMT 데이터 미활용) — ★★★

PMT_국내 41건이 DB에 있으나 대시보드에서 전혀 사용하지 않음.

**추가 항목**:
- DSO (Days Sales Outstanding) — 매출채권 회전일수
- 미수금 aging (30/60/90일 이상)
- 고객별 결제 현황 및 지연 고객 경보
- 월별 입금 추이 vs 출고(매출 인식) 추이

**가치**: 현금 흐름 가시성. 출고는 했는데 입금이 안 되는 고객 조기 식별.

#### B. PO→EXW 공장 리드타임 분석 — ★★★

PO 테이블에 order_date(발주일), factory_exw(EXW 예정일) 존재.

**추가 항목**:
- 리드타임 분포 (히스토그램)
- 제품별 평균 리드타임 비교
- 리드타임 추이 (월별 — 개선/악화 방향)
- 리드타임 vs 약속 납기 갭 분석

**가치**: 공장 납기 예측의 핵심. 수주 시 고객에게 리드타임 안내 정확도 향상.

#### C. 수주→출고 전체 Cycle Time — ★★★

SO period(수주월) + DN dispatch_date(출고일) 연결 가능.

**추가 항목**:
- 주문접수~고객인도 전체 Cycle Time
- 국내 vs 수출 Cycle Time 비교
- 병목 구간 식별: 수주→PO발주, PO발주→EXW, EXW→출고

**가치**: 전체 밸류체인의 병목 가시화. 어디서 시간이 소비되는지.

#### D. 환율 영향 분석 — ★★☆

SO에 USD/EUR 원화 환산 금액이 있으므로 역산 가능.

**추가 항목**:
- 적용 환율 추이
- 환율 변동이 매출(KRW)에 미치는 영향
- 통화별(USD/EUR) 수주 비중

#### E. 단순 수요 예측 — ★★☆

3개월 수주 추이 + Backlog 데이터로 가능.

**추가 항목**:
- 3개월 이동평균 기반 향후 매출 예측
- Backlog 기반 향후 출고 예정 금액
- 신규 수주 필요량 (목표 대비)

### 3.2 구조적 개선

#### F. Executive Summary 페이지 — ★★★

현재 "오늘의 현황"은 운영 실무자용. 경영진이 30초 안에 사업 상태를 파악할 페이지가 없음.

**필요 구성**:
```
┌─────────────────────────────────────────────────────┐
│              NOAH Q1 2026 Executive Summary          │
├──────────┬──────────┬──────────┬──────────┬─────────┤
│ 수주     │ 출고     │ 마진율   │ Backlog  │ B2B     │
│ 64.1억   │ xx억     │ xx.x%   │ 40.3억   │ x.xx    │
│ (전월비) │ (전월비) │ (전월비) │ (Cover)  │ (추이)  │
├──────────┴──────────┴──────────┴──────────┴─────────┤
│ [수주/출고 미니 추이]  [Top 리스크 3개]  [Action]    │
└─────────────────────────────────────────────────────┘
```

#### G. 기간 비교 (YoY, QoQ) — ★★☆

현재 단일 기간 필터만 가능. 데이터가 1년 이상 쌓이면 전년 동기 대비가 핵심.

**필요**:
- 선택 기간 vs 비교 기간 듀얼 필터
- 주요 KPI에 전년 동기 대비 증감률 자동 표시

#### H. 임계값 기반 자동 경고 시스템 — ★★☆

현재 저마진 경보(20%)만 존재. 더 넓은 범위의 자동 경고 필요.

**제안 임계값**:
| 지표 | 경고 기준 | 위험 기준 |
|---|---|---|
| OTD | < 90% | < 80% |
| Backlog Cover | < 2개월 | < 1개월 |
| Top 1 고객 비중 | > 25% | > 35% |
| Past Due Ratio | > 10% | > 20% |
| 마진율 | < 25% | < 15% |
| DSO | > 45일 | > 60일 |

## 4. 데이터 확장 시 가능해지는 분석 (중장기)

| 경쟁사 분석 (Lost Orders) | 실주/경쟁 데이터 | 영업 보고 | 시장 점유율 방어 |

| 고객 만족도 (NPS) | 설문/피드백 | 별도 수집 | 리텐션 예측 |
